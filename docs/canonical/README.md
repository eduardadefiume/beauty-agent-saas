# Documentos canônicos

Estes documentos governam a implementação da FV-01. A ordem de precedência é:

1. instrução explícita posterior da fundadora;
2. escopo aprovado;
3. requisitos consolidados;
4. modelo de domínio aprovado;
5. arquitetura aprovada;
6. backlog autorizado.

William e Jack são exemplos de configuração por `tenant_id`; seus nomes nunca controlam lógica de
produção. Sinal e pagamento continuam fora do piloto, mesmo que referências antigas mencionem a
capacidade futura.
